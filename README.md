## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or 22+
- npm / pnpm / yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/niraj7780/portfolio.git
cd portfolio

# Install dependencies
npm install

# Run the local development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the application.

### Build for Production
```bash
npm run build
npm run start
```
