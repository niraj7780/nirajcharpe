# Niraj Charpe — Portfolio

A minimal, evidence-based developer portfolio for **Niraj Charpe**, a software engineer at **HCLTech**, based in Noida, India.

Built with **Next.js 16 (App Router) · TypeScript · Tailwind CSS 4**. No UI framework, no analytics, no tracking, and no third-party scripts.

## What is included

- **Landing page** (`/`) with Hero, About, Skills, six featured projects, live GitHub repositories, Journey, Contact, and Footer.
- **Live repository feed** sourced from the public GitHub API. It supports category filters, a "show everything" toggle, relevance sorting, rate-limit handling, and a fallback link.
- **Resume page** (`/resume`) with a print stylesheet and a link to the generated PDF.
- **Resume PDF** (`/resume.pdf`) generated by a dependency-free Node script.
- **SEO** metadata, canonical URL, Open Graph image, JSON-LD Person schema, sitemap, robots rules, and manifest.
- **Accessibility** features: skip link, semantic landmarks, keyboard-visible focus, reduced-motion support, and content that remains visible without JavaScript.

## Getting started

```bash
npm install
npm run dev      # http://localhost:3000
npm run lint     # ESLint
npx tsc --noEmit # TypeScript check
npm run build    # production build
npm start        # serve the production build
```

## Environment variables

Only one optional variable is supported:

| Variable | Purpose | Default |
| --- | --- | --- |
| `NEXT_PUBLIC_SITE_URL` | Canonical site URL used in metadata, sitemap, robots, and JSON-LD | `https://nirajcharpe.is-a.dev` |

No API keys are required for the portfolio. The GitHub repository section uses the public, unauthenticated GitHub API.

## Featured projects and why they were selected

The six featured projects were chosen from the public repositories after checking their source, README, and live status. The ranking is based on technical depth, working functionality, implementation effort, and relevance to software roles.

1. **CareerLens AI** — full-stack product with a Next.js frontend, FastAPI backend, real document parsing, and Gemini integration.
2. **MiniGPT** — from-scratch transformer implementation. Strong evidence of computer-science fundamentals and independent implementation.
3. **DevCode Online Compiler** — security-sensitive systems project with Docker sandboxing, Monaco, and explicit deployment constraints.
4. **MedAI Medical Query Generator** — AI integration with safety-focused prompt design and a clearly stated informational-only scope.
5. **NirajVersant** — a complete, deployed education product built as a self-contained app with browser speech APIs.
6. **Django E-Commerce** — a full server-rendered purchase flow with authentication, sessions, Stripe Checkout, and orders.

Four additional projects are shown separately:

- **Bank Management System** — role-based business logic and SQLite.
- **All Tools In One Place** — larger Next.js utility platform.
- **Weather Alert Bot** — external API integration, Twilio/WhatsApp, and a React Native client.
- **File Converter** — a small deployed browser utility.

Unfinished scaffolding repositories, empty repositories, forks, and duplicate bot experiments are hidden from the live feed by default. The feed includes a toggle to show everything.

## Content accuracy

This portfolio intentionally avoids claims that cannot be backed by source code or the information provided.

- **No invented education details.** School, board, grades, college, degree, and graduation dates are not listed.
- **No invented dates.** The HCLTech software engineer entry is described without a start date because no date was confirmed.
- **No invented job titles.** The site consistently describes the role as "software engineer at HCLTech".
- **No invented freelance or e-commerce history.** Earlier drafts contained freelance and dropshipping claims that were not confirmed; they have been removed.
- **No skill percentages.** Skills are grouped by evidence level instead.
- **No unverified live demo.** MedAI's public deployment currently returns an HTTP 500, so its live link is not shown. The source repository is still linked.
- **Medical and trading language stays cautious.** MedAI is described as an informational prototype, not a clinical tool.

## Generating the resume PDF

`public/resume.pdf` is generated by a dependency-free script that writes a valid single-page A4 PDF using Helvetica base fonts:

```bash
node scripts/generate-resume.mjs
```

The script throws an error if the content overflows one page. Edit the content in `scripts/generate-resume.mjs`, then re-run it. The HTML resume at `/resume` is maintained separately in `src/app/resume/page.tsx`; keep the two in sync.

## Deployment

No deployment was performed as part of this work. To deploy on Vercel:

1. Import the GitHub repository.
2. Set **Root Directory** to `niraj-portfolio`.
3. Framework preset: **Next.js**. Build command: `npm run build`.
4. Add the domain `nirajcharpe.is-a.dev` in Vercel and point its DNS to Vercel.
5. Optionally set `NEXT_PUBLIC_SITE_URL` to the final production URL.

The repository root still contains the previous static site (`index.html`) and the `CNAME` file. Do not overwrite them unless you intend to replace the old site. GitHub Pages cannot serve this Next.js application; use Vercel, Netlify, or Cloudflare Pages.

## Known issues and security notes

- The GitHub feed uses the unauthenticated public API, which is limited to 60 requests per hour per IP. The UI handles failures and provides a retry button and direct GitHub fallback.
- MedAI's public demo is currently down; the repository remains linked.
- The public `weather_alert_bot` repository contains a tracked `.env` file. The portfolio does not read or expose it, but the repository owner should review the file and rotate any keys that may have been committed.
- Live demo availability can change. Re-check links before publishing.
